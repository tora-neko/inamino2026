【GitHub:index.htmlを新しいものに置き換える手順】
1.	GitHubにログインし、対象のリポジトリを開く
2.	index.htmlがあるフォルダを開く
3.	右上の「Add file」→「Upload files」をクリック
4.	新しいindex.htmlをドラッグ&ドロップ(ファイル名は既存と同じ、大文字小文字も一致させる)
5.	下の欄に更新メモを書き、「Commit changes」を押す
6.	1〜数分待ってからサイトを開く
7.	変わっていなければ、Ctrl+Shift+R(Macは Cmd+Shift+R)で強制再読み込み
注意:ファイル名が違うと上書きされず、別ファイルとして追加されてしまいます。
